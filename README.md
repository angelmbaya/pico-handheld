# Pico Handheld

**Status: Early development · In progress**

A personal project to build a handheld gaming device around the Raspberry Pi Pico 2, exploring embedded software and hardware-software integration.

## Project Goal

Develop a playable handheld prototype that connects microcontroller firmware with a display and physical controls.

The project focuses on learning how to handle user input, update graphics, and organize embedded code while working within hardware constraints.

## Planned Technology

- Raspberry Pi Pico 2
- C/C++ firmware
- SPI display
- Physical buttons

## Current Progress

The project is in its early stages. Hardware integration and firmware development are ongoing, and a complete playable device is not yet available.

This repository will document the code, hardware setup, and development milestones as the prototype takes shape.

## Initial Milestones

- [ ] Document the components and wiring.
- [ ] Initialize the display and draw a basic shape.
- [ ] Read a button press.
- [ ] Move an on-screen object using physical controls.
- [ ] Build a simple playable game.
- [ ] Document the prototype with photos and a demonstration.

## Future Exploration

Potential additions include audio, microSD storage, and a custom enclosure. These are planned areas to explore rather than completed features.
